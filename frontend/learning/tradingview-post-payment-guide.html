TRADINGVIEW SETUP · STEP 03

결제 후 상태 선언 & Pine Script 시작

결제와 자격 확인이 끝난 뒤, 차트 화면에서 Pine Editor를 열어 전략을 작성하고 백테스트하는 전체 클릭 순서입니다.

1. 상태 선언 화면 확인하기

교육용 참고 이미지입니다. 실제 자격 확인 항목과 화면 구성은 계정·지역·플랜에 따라 달라질 수 있습니다.

  1. 팝업의 상태 선언 버튼을 선택합니다.
  2. 표시되는 질문을 읽고 본인의 구독자 자격에 맞는 정보를 정확하게 제출합니다.
  3. 확인이 끝나면 차트와 Pine Editor를 열어 전략 테스트를 시작합니다.
자격 관련 문항은 실제 상황과 다르게 입력하면 안 됩니다. 판단이 어렵다면 TradingView 공식 도움말 또는 고객지원에서 최신 기준을 확인하세요.

2. Pine Editor를 열고 전략 테스트하기

아래 그림의 주황색 ①처럼 차트 오른쪽 세로 도구 모음의 Pine 아이콘을 클릭합니다. 아이콘이 접혀 있으면 도구 모음을 확장하거나 아래쪽 아이콘을 확인하세요.

① 현재 종목명 클릭 → ② 삼성전자 또는 005930 입력 → 검색 결과의 KRX:005930 선택

삼성전자를 선택한 뒤, 상단의 1날 버튼을 클릭하면 하루 단위 캔들인 일봉으로 볼 수 있습니다.

차트 위에서 마우스 휠로 확대·축소하고, 오른쪽 상단 통화가 KRW인지와 오른쪽 가격축의 현재가를 확인합니다.

삼성전자 일봉 차트가 열린 뒤, 화살표가 가리키는 오른쪽 세로 도구 모음의 Pine Script 아이콘을 클릭합니다. 아이콘 위에 마우스를 올려 ‘Pine’이라는 도움말이 표시되는지 먼저 확인하세요.

Pine Editor가 열리면 기본 코드를 간단한 종가 선 지표로 바꾸고 차트에 넣기를 눌러 첫 동작을 확인합니다.

1
현재 종목명 USDKRW를 클릭합니다.

차트 왼쪽 상단의 종목명을 누르면 그림처럼 심볼 찾기 창이 열립니다.

2
검색창에 삼성전자 또는 005930을 입력합니다.

결과 중 Samsung Electronics Co., Ltd. · KRX:005930 행을 클릭합니다. 유사한 이름의 해외 종목이 보이면 거래소 KRX와 코드 005930을 꼭 확인하세요.

3
삼성전자 차트가 열린 뒤 기간을 1일로 맞춥니다.

일봉 기준 백테스트를 시작할 수 있습니다. 이후 오른쪽 세로 도구 모음의 Pine 아이콘을 클릭합니다.

4
차트 화면을 확인하고 원하는 구간으로 이동합니다.

차트 위에서 마우스 휠을 위·아래로 굴려 확대·축소합니다. 이전 가격 구간은 마우스 왼쪽 버튼으로 차트를 끌어 이동합니다. 확대 중 현재 위치를 유지하려면 화면에 표시되는 안내처럼 Ctrl 키를 함께 누릅니다.

오른쪽 상단 통화가 KRW인지, 가격축과 우측 종목 카드의 현재가가 005930 · KRW로 표시되는지 확인합니다.

5
오른쪽 도구 모음의 Pine Script 아이콘을 클릭합니다.

그림의 화살표 위치에 있는 아이콘 위에 마우스를 올려 Pine이라는 도움말이 보이는지 확인한 뒤 클릭합니다. Pine Editor가 플로팅 패널 또는 도킹 패널로 열립니다.

6
가장 간단한 지표로 먼저 동작을 확인합니다.

현재 열린 코드 영역을 Ctrl+A(Mac: ⌘A) → Backspace로 비운 뒤 아래 코드를 붙여넣습니다.

//@version=6
indicator("삼성전자 종가 테스트", overlay=true)
plot(close, color=color.blue, linewidth=2)

저장 또는 Ctrl+S(Mac: ⌘S)를 누르고 차트에 넣기를 클릭합니다. 차트 위에 파란 선이 보이면 Script 생성·적용이 정상입니다.

7
이동평균 전략으로 확장합니다.

파란 종가 선이 보이면, 코드 전체를 아래 전략으로 바꿔 백테스트를 준비합니다. 새 빈 파일이 꼭 필요할 때만 에디터 상단의 현재 스크립트 이름 또는 ⋯ 메뉴에서 New strategy를 선택합니다.

//@version=6
strategy("MA Cross Practice", overlay=true)
fast = ta.sma(close, 20)
slow = ta.sma(close, 60)
if ta.crossover(fast, slow)
    strategy.entry("Long", strategy.long)
if ta.crossunder(fast, slow)
    strategy.close("Long")
plot(fast, color=color.blue)
plot(slow, color=color.orange)

Save 또는 Ctrl+S(Mac: ⌘S)를 누릅니다.

8
상단의 Add to chart를 클릭합니다.

차트에 매수·매도 신호가 표시됩니다. 오류가 뜨면 에디터 하단의 오류 메시지부터 수정합니다.

9
Strategy Tester에서 결과를 봅니다.

총손익, 승률, 최대 낙폭(MDD), 거래 목록을 확인하고 기간·종목을 바꿔 재검증합니다.

Pine Strategy Tester는 백테스트 도구입니다. 실제와 같은 수동 주문 연습은 Trading Panel의 Paper Trading에서 별도로 진행하며, 수익 결과만 보고 실제 매매를 결정하지 마세요.
