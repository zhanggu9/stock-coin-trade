01 · INTRODUCTION

SAM은 무엇인가요?

공식 GitHub
AWS SAM

CloudFormation을 확장한 오픈소스 서버리스 애플리케이션 모델입니다. AWS::Serverless::Function 같은 간결한 선언을 실제 AWS 리소스로 변환합니다.

SAM CLI

sam 명령을 제공하는 별도 도구입니다. 초기화, 검증, 빌드, 로컬 실행, 배포와 로그 확인을 한 흐름으로 묶습니다.

Docker

sam build --use-container와 sam local 명령이 Lambda와 비슷한 실행 이미지를 사용할 때 필요합니다. AWS 배포 자체에 항상 필요한 것은 아닙니다.

작성template.yaml→변환SAM Transform→배포CloudFormation Stack→생성Lambda · IAM 등

구분: aws/serverless-application-model은 SAM 규격과 변환 구현 저장소이고, aws/aws-sam-cli는 터미널에서 사용하는 CLI 저장소입니다.

02 · INSTALL

Linux에 SAM CLI 설치

PRECHECK

먼저 설치 여부 확인

이미 설치돼 있으면 다시 설치하지 않습니다. 로컬 실행에는 Docker 데몬도 확인합니다.

환경 확인
uname -m
command -v sam || true
sam --version
aws --version
docker --version
docker info
X86_64

x86_64 설치

GitHub의 최신 공식 설치 ZIP을 내려받아 설치합니다.

Linux x86_64
curl -L "https://github.com/aws/aws-sam-cli/releases/latest/download/aws-sam-cli-linux-x86_64.zip" \
  -o aws-sam-cli-linux-x86_64.zip
unzip aws-sam-cli-linux-x86_64.zip -d sam-installation
sudo ./sam-installation/install
sam --version
ARM64

arm64 설치

uname -m이 aarch64이면 arm64 패키지를 사용합니다.

Linux arm64
curl -L "https://github.com/aws/aws-sam-cli/releases/latest/download/aws-sam-cli-linux-arm64.zip" \
  -o aws-sam-cli-linux-arm64.zip
unzip aws-sam-cli-linux-arm64.zip -d sam-installation
sudo ./sam-installation/install
sam --version
AWS ACCESS

AWS CLI 자격증명 확인

배포 단계에서만 필요합니다. 개인 키를 템플릿이나 저장소에 기록하지 않습니다.

호출자 확인
aws configure list
aws sts get-caller-identity
aws configure get region
03 · QUICK START

가장 작은 SAM 프로젝트 사용법

다음: Lambda/API 실습
STEP 1

프로젝트 생성

처음에는 공식 템플릿으로 디렉터리 구조와 명령 흐름부터 확인합니다.

초기화
sam init
# 선택 예시
# Template source: AWS Quick Start Templates
# Runtime: python3.11
# Package type: Zip

cd sam-app
find . -maxdepth 2 -type f | sort
STEP 2

최소 템플릿 이해

Transform, 함수 타입, 코드 위치, 런타임과 핸들러가 핵심입니다.

template.yaml
AWSTemplateFormatVersion: '2010-09-09'
Transform: AWS::Serverless-2016-10-31
Resources:
  PracticeFunction:
    Type: AWS::Serverless::Function
    Properties:
      CodeUri: src/
      Runtime: python3.11
      Handler: app.lambda_handler
      Timeout: 10
STEP 3

검증과 빌드

YAML과 리소스 규칙을 검사한 후 Lambda 실행 구조로 빌드합니다.

validate → build
sam validate --lint
sam build

# 네이티브 패키지가 있으면 Lambda 유사 컨테이너에서 빌드
sam build --use-container
STEP 4

로컬 단일 호출

이벤트 JSON을 핸들러에 전달합니다. 로컬 컨테이너 호출에는 Docker가 실행 중이어야 합니다.

local invoke
mkdir -p events
printf '{"message":"hello"}\n' > events/basic.json

sam local invoke PracticeFunction \
  --event events/basic.json
sam deploy --guided # 첫 AWS 배포 설정을 대화형으로 저장sam deploy # 저장된 samconfig.toml로 반복 배포sam delete # 실습 CloudFormation 스택과 배포 산출물 정리
